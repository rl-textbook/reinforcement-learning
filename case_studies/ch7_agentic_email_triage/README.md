# Case Study: Agentic RL for Customer Support Email Triage

**Chapter 7 — Agentic Architectures in Reinforcement Learning**

## Problem
Build a progressive agentic system that learns to triage customer support
emails using RL-learned tool use, LLM classification, planning, and
persistent customer memory.

## Key Findings
- Level 1 (Random): Baseline performance
- Level 2 (LLM Classification): Significant improvement from keyword-based classification
- Level 3–4 (RL Tool Use): RL learns which investigation tools are relevant
- Level 5 (LLM Planning): Semantic guidance accelerates RL tool learning
- Level 6 (Memory): Persistent memory improves handling of repeat customers
