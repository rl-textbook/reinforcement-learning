# Case Study: DQN vs REINFORCE vs Actor-Critic

**Chapter 4 — Deep Reinforcement Learning**

## Problem
Compare three deep RL paradigms on CartPole-v1: value-based (DQN),
policy gradient (REINFORCE), and actor-critic methods.

## Key Findings
- DQN achieves stable performance via experience replay and target networks
- REINFORCE exhibits high variance but can reach optimal performance
- Actor-Critic combines fast learning with reduced variance
